## 🌟 1. 왜 중국 본토 대신 '홍콩(Hong Kong)' 서버를 쓸까요?

* **중국 본토(베이징, 상하이)**: 외국인이 웹사이트를 열려면 중국 정부의 까다로운 허가증(**ICP 비안**)을 받아야 해서 몇 달씩 걸립니다.
* **홍콩(Hong Kong)**: **정부 허가증(ICP)이 전혀 필요 없습니다!** 누구나 1분 만에 서버를 만들어 전 세계에 공개할 수 있습니다.
* **속도는 어떨까요?**: 홍콩은 중국 본토(심천, 광저우, 상하이)와 지리적으로 바로 붙어 있어서, 중국 학생들이 접속해도 **0.03~0.05초(30~50ms)** 만에 번개처럼 페이지가 열립니다! ⚡

## 🛠️ 3. 실전 배포 3단계 (따라만 하세요!)

### [1단계] 홍콩 클라우드 서버 1대 빌리기 (월 약 7,000원 ~ 15,000원)

가장 유명하고 안정적인 **알리바바 클라우드(Alibaba Cloud)** 또는 **텐센트 클라우드(Tencent Cloud)**를 사용합니다.

1. **[알리바바 클라우드(alibabacloud.com)](https://www.alibabacloud.com)** 에 접속하여 회원가입합니다.
2. 상단 메뉴에서 **[Elastic Compute Service (ECS)]** 또는 **[Simple Application Server]** 클릭 ➔ **[Create / 구매]** 클릭!
3. 아래 설정 3가지만 딱 확인하고 결제합니다:
   * **지역(Region)**: 반드시 **`Hong Kong (香港)`** 선택! 🇭🇰
   * **운영체제(OS)**: **`Ubuntu 22.04 64bit`** 선택!
   * **사양**: **`2 vCPU / 2GB RAM`** (가장 저렴한 기본형)
4. 결제가 완료되면 **서버의 공용 IP 주소(Public IP)**가 화면에 뜹니다. (예: `47.242.123.45`)

---

### [2단계] 내 컴퓨터에서 홍콩 서버로 접속하기

1. 내 윈도우 컴퓨터에서 **PowerShell(파워셸)** 프로그램을 엽니다.
2. 아래 명령어를 입력하고 엔터를 칩니다 (IP 주소 부분에 내 서버 IP를 넣으세요):
   ```bash
   ssh root@47.242.123.45
   ```
3. `Are you sure you want to continue connecting (yes/no)?` 라고 물어보면 `yes` 입력 후 엔터!
4. 서버 비밀번호를 입력하면 홍콩 서버 접속 완료! 🚀

---

### [3단계] 마법의 1줄 명령어 붙여넣기 (자동 배포 끝!)

서버 검은색 화면에 **아래 명령어를 그대로 복사해서 붙여넣고 엔터**를 누르세요.  
(도커 설치부터 웹사이트 실행까지 컴퓨터가 알아서 100% 자동으로 처리합니다!)

```bash
git clone https://github.com/lsanghak-steve/english_edu.git && cd english_edu/deploy_hk && chmod +x deploy.sh && ./deploy.sh
```

☕ **잠시 커피 한 모금 마시며 2~3분만 기다리면 끝납니다!**

## 🎉 4. 배포 완료 확인하기!

설치가 끝나면 웹 브라우저(크롬, 엣지, 웨일 등)를 열고 주소창에 내 서버 IP를 쳐보세요:

* **학생/학부모 학습 메인 화면**:  
  👉 `http://내_서버_IP` (예: `http://47.242.123.45`)
* **중국어 전용 랜딩 페이지**:  
  👉 `http://내_서버_IP/landing_zh`
* **선생님/학원 관리자 페이지**:  
  👉 `http://내_서버_IP/admin`

## ❓ 5. 자주 묻는 질문 (FAQ)

### Q1. 나중에 코드를 수정하고 깃허브에 올렸는데, 서버에는 어떻게 반영하나요?
홍콩 서버에 접속해서 딱 이 명령어 한 줄만 치면 10초 만에 최신 코드로 자동 업데이트됩니다:
```bash
cd ~/english_edu/deploy_hk && ./deploy.sh
```

### Q2. `http://` 대신 자물쇠 모양(`https://`) 보안 도메인을 연결하고 싶어요.
가비아(Gabia)나 후이즈 등에서 도메인(예: `stevevoca.com`)을 구매한 뒤, DNS 관리에서 서버 IP(`47.242.123.45`)를 연결하면 됩니다. 무료 SSL 인증서(Let's Encrypt)도 명령어 한 번으로 적용됩니다!

### Q3. 서버를 끄거나 다시 켜고 싶을 때는 어떻게 하나요?
* **서버 중지**: `docker-compose down`
* **서버 다시 켜기**: `docker-compose up -d`
* **현재 상태 보기**: `docker ps`
