## 🌟 1. 왜 중국 본토 대신 '홍콩(Hong Kong)' 서버를 쓸까요?

* **중국 본토(베이징, 상하이)**: 외국인이 웹사이트를 열려면 중국 정부의 까다로운 허가증(**ICP 비안**)을 받아야 해서 몇 달씩 걸립니다.
* **홍콩(Hong Kong)**: **정부 허가증(ICP)이 전혀 필요 없습니다!** 누구나 1분 만에 서버를 만들어 전 세계에 공개할 수 있습니다.
* **속도는 어떨까요?**: 홍콩은 중국 본토(심천, 광저우, 상하이)와 지리적으로 바로 붙어 있어서, 중국 학생들이 접속해도 **0.03~0.05초(30~50ms)** 만에 번개처럼 페이지가 열립니다! ⚡

## 🛠️ 3. 실전 배포 3단계 (따라만 하세요!)

### [1단계] 홍콩 클라우드 서버 1대 빌리기 (월 약 5,000원 ~ 8,000원)

복잡한 네트워크 설정이 필요 없는 초보자 전용 서비스인 **알리바바 클라우드의 [Simple Application Server (간편 서버)]**를 추천합니다.

#### 1. 회원가입 및 결제 수단 등록
1. **[알리바바 클라우드 공식 홈페이지(alibabacloud.com)](https://www.alibabacloud.com)** 에 접속하여 **[Free Account / 무료 가입]**을 누릅니다.
2. 이메일 인증 후 **[Individual(개인)]** 선택 ➔ 해외 결제 가능한 카드(비자/마스터 등)를 등록합니다.

#### 2. 서버 구매 페이지로 이동
1. 로그인 후 상단 검색창에 **`Simple Application Server`** 를 검색하여 클릭합니다.
   (또는 왼쪽 메뉴 [Products] ➔ [Compute] ➔ [Simple Application Server])
2. 파란색 **[Create Server]** 또는 **[Buy Now]** 버튼을 클릭합니다.

#### 3. 4가지 필수 옵션 선택 (화면 체크리스트)
* **① Region (지역)**: **`Asia Pacific` ➔ `Hong Kong (香港)`** 을 반드시 선택합니다! 🇭🇰
  *(홍콩을 골라야 중국 정부 허가증(ICP) 없이 중국 본토 학생들이 0.05초 만에 접속할 수 있습니다)*
* **② Image (운영체제)**: **[OS Images]** 탭을 누른 후 **`Ubuntu` ➔ `Ubuntu 22.04 LTS`** 를 선택합니다.
* **③ Instance Plan (사양/가격)**:
  * 가장 저렴한 **월 $3.50 ~ $6.00 (약 4,800원~8,000원)** 플랜을 선택합니다.
  * 사양: **1~2 vCPU / 1~2GB RAM / 40~60GB SSD / 1TB~2TB 트래픽**
  *(이 사양이면 하루 수만 명의 학생이 단어장을 이용해도 충분히 쾌적합니다)*
* **④ Subscription Duration (기간)**: **`1 Month (1개월)`** 선택 (언제든 필요 없으면 해지 가능)

#### 4. 결제 완료 및 비밀번호 설정
1. 우측 하단 **[Buy Now]** ➔ **[Pay]** 를 눌러 결제를 마칩니다.
2. 서버 목록(Servers)으로 돌아오면 약 1분 뒤 서버 상태가 **`Running (실행 중)`** 으로 바뀝니다.
3. 생성된 서버 이름을 클릭 ➔ 왼쪽 메뉴 **[Server Management] ➔ [Reset Password]** 클릭:
   * **사용자 이름**: `root`
   * **새 비밀번호**: 내가 기억하기 쉬운 영문+숫자+특수문자 비밀번호 입력 후 서버 재부팅(Restart) 확인.

#### 5. 방화벽(Firewall) 포트 열기 (초중요! ⚠️)
외부에서 웹사이트로 들어올 수 있도록 통로를 열어줍니다.
1. 왼쪽 메뉴 **[Firewall (방화벽)]** 클릭 ➔ **[Add Rule (규칙 추가)]** 클릭!
2. 아래 3개 포트가 열려 있는지 확인하고, 없으면 추가합니다:
   * **포트 80** (일반 웹사이트용 - HTTP)
   * **포트 443** (보안 웹사이트용 - HTTPS)
   * **포트 22** (원격 접속용 - SSH)
3. 화면 상단에 적힌 **서버의 공용 IP 주소(Public IP)**를 복사해둡니다. (예: `47.242.123.45`)

### [2단계] 내 컴퓨터에서 홍콩 서버로 접속하기

1. 내 윈도우 컴퓨터에서 **PowerShell(파워셸)** 프로그램을 엽니다.
2. 아래 명령어를 입력하고 엔터를 칩니다 (IP 주소 부분에 내 서버 IP를 넣으세요):
   ```bash
   ssh root@47.242.123.45
   ```
3. `Are you sure you want to continue connecting (yes/no)?` 라고 물어보면 `yes` 입력 후 엔터!
4. 서버 비밀번호를 입력하면 홍콩 서버 접속 완료! 🚀

### [3단계] 마법의 1줄 명령어 붙여넣기 (자동 배포 끝!)

서버 검은색 화면에 **아래 명령어를 그대로 복사해서 붙여넣고 엔터**를 누르세요.  
(도커 설치부터 웹사이트 실행까지 컴퓨터가 알아서 100% 자동으로 처리합니다!)

```bash
git clone https://github.com/lsanghak-steve/english_edu.git && cd english_edu/deploy_hk && chmod +x deploy.sh && ./deploy.sh
```

☕ **잠시 커피 한 모금 마시며 2~3분만 기다리면 끝납니다!**

## ❓ 5. 자주 묻는 질문 (FAQ)

### Q1. 나중에 코드를 수정하고 깃허브에 올렸는데, 서버에는 어떻게 반영하나요?
홍콩 서버에 접속해서 딱 이 명령어 한 줄만 치면 10초 만에 최신 코드로 자동 업데이트됩니다:
```bash
cd ~/english_edu/deploy_hk && ./deploy.sh
```

### Q2. `http://` 대신 자물쇠 모양(`https://`) 보안 도메인을 연결하고 싶어요.
가비아(Gabia)나 후이즈 등에서 도메인(예: `stevevoca.com`)을 구매한 뒤, DNS 관리에서 서버 IP(`47.242.123.45`)를 연결하면 됩니다. 무료 SSL 인증서(Let's Encrypt)도 명령어 한 번으로 적용됩니다!

### Q3. 서버를 끄거나 다시 켜고 싶을 때는 어떻게 하나요?
* **서버 중지**: `docker-compose down`
* **서버 다시 켜기**: `docker-compose up -d`
* **현재 상태 보기**: `docker ps`
