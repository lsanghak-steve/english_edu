# 📖 초등 필수 영단어 500 학습 프로그램 기능 명세서

## 1. 🌟 주요 시스템 개요
- **기술 스택**: Next.js (App Router), React, Vanilla CSS, Supabase (Cloud Database)
- **배포 환경**: Vercel Cloud & Local Dev Server
- **클라우드 실시간 동기화**: 534개 영단어 DB, 학생 계정/프로필, 퀴즈 오답노트, 출석 달력 도장(💮) 및 날짜별 복습 리스트

---

## 2. 📱 학생 학습 핵심 기능
1. **🎴 플래시카드 연동 학습**:
   - 영단어 + 발음기호 + 2원적 한글 뜻 + 고화질 그림 연동
   - 추천 학습 예문(영어/한글) 및 예문 전용 원어민 TTS 음성 재생
   - 🎙️ 내 발음 실시간 녹음기 & 음성 파동/높낮이 Visualizer 그래프

2. **🚀 다음 단어 학습 (Next Random Set)**:
   - 현재 세트 학습 완료 시 미학습 단어 중 학생 지정 목표량(5~30단어) 무작위 추출
   - 2회차/3회차 회차별 연속 학습 지원 (`🔥 오늘 N회차 학습 중!`)

3. **❓ 3단계 스마트 영단어 퀴즈**:
   - **1단계 🔊 소리 퀴즈**: 단어 소리를 듣고 한글 뜻 맞히기 (완료 시 2단계 자동 연결)
   - **2단계 🧩 스펠링 선택 퀴즈 (필수 완수)**: 한글 뜻보고 영어 단어 4지선다 선택 (완수 시 출석 도장 💮 자동 찍기)
   - **3단계 ✍️ 스펠링 직접 쓰기 퀴즈**: 주관식 입력 퀴즈
   - **❌ 실시간 오답노트 자동 저장**: 틀린 단어 Supabase 클라우드 DB 자동 동기화

4. **📅 출석 달력 ☁️**:
   - 2단계 퀴즈 완수 시 도장(💮) 자동 발급 및 Supabase 클라우드 DB 연동
   - 과거 찍힌 도장을 클릭하면 그날 공부한 영단어 목록 팝업 복습 제공

5. **⭐ 개인 단어장 & ❌ 퀴즈 오답노트 ☁️**:
   - 내가 직접 등록하는 나만의 개인 단어장
   - 클라우드 DB에 동기화된 틀린 단어 모음 및 복습 후 마스터(삭제) 기능

---

## 3. 👥 학생 & 학부모 계정 시스템
- **입력 항목**: 학생 이름, 학년(초등 1~6학년, 중학생 1~3학년, 고등학생 1~3학년, 대학생 및 성인), 하루 목표 학습량, 학생 PIN(4자리), 학부모 이름, 학부모 연락처, 학부모 PIN(4자리)
- **클라우드 연동**: Supabase `student_profiles` 테이블 실시간 동기화

---

## 4. 🏫 센터 관리자 페이지 (`/admin`)
- 4자리 관리자 비밀번호 인증 로그인 (기본 PIN: `0000`)
- **📖 534개 영단어 DB 관리자**: 단어 검색, 엑셀 템플릿 다운로드, 엑셀 대량 업로드, 신규 단어 등록/수정/삭제
- **👥 학생 및 학부모 종합 관리자**: 전체 등록 학생 목록 한눈에 조회, 신규 학생 등록, 정보 수정, 계정 삭제
