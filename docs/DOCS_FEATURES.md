## 📌 1. 핵심 시스템 구조 및 특징

- **클라우드 DB 실시간 연동**: Supabase 클라우드 데이터베이스(`words`, `student_profiles`, `student_attendance`, `student_wrong_answers`)와 동기화되어 로컬 환경과 Vercel 웹사이트에서 동일한 데이터를 유지합니다.
- **이모지 자동 정화 시스템**: DB 저장 및 사용자 화면에 등록되는 학생/학부모 성함에서 이모지 기호를 자동으로 정화하여 깔끔한 이름을 유지합니다.
- **반응형 웹 UI 디자인**: PC 모니터부터 태블릿, 스마트폰 모바일 화면까지 모든 기기 크기에서 최적의 UI 레이아웃을 지원합니다.

## 🚀 2. 주요 기능 및 모듈별 상세 안내

### 1️⃣ 🎓 학생 / 학부모 관문 로그인 시스템 (`StudentLoginPage.js`)
- **학생 로그인**: 학생 이름(예: `김철수`, `이영희`, `이승현`, `이수민`)과 4자리 비밀번호(PIN, 기본 `1234`) 입력 후 즉시 본인 맞춤 학습 시작.
- **👨‍👩‍👧‍👦 학부모 전용 로그인 모달**: 
  - 센터 관리자와 연결된 학부모 성함(예: `이상학`)과 학부모 PIN(기본 `0815` 또는 `5678`) 입력 시 로그인.
  - 학부모에 등록된 **모든 자녀(다자녀)**의 학습 성취도를 한곳에서 통합 조회 가능.

---

### 2️⃣ 🎴 플래시카드 단어 학습 & 원어민 예문 TTS & 음성 높낮이 그래프 (`page.js`)
- **그림 및 단어 학습**: 534개 초등 영단어의 알파벳, 발음기호, 한글 뜻, 파닉스 카테고리 표시.
- **🔊 원어민 TTS 음성 들려주기**: 
  - `🔊 단어 발음 듣기` 및 카드 뒷면 `🔊 예문 문장 발음 듣기` 지원 (원어민 브라우저 합성 음성).
- **🎙️ 내 발음 녹음 & 실시간 음성 파동 Visualizer**:
  - 마이크로 본인의 영어 발음을 녹음하고, 음성 높낮이 주파수를 실시간 그래프파동으로 시각화하여 확인.

### 3️⃣ 📋 500개 단어 리스트 & 실시간 필터 (`WordListSection.js`)
- 초등 필수 영단어 534개 전체 리스트 조회.
- 단어 검색, 학년별/카테고리별 실시간 필터링 기능.
- 목록에서 바로 발음(🔊)을 재생하여 청취 가능.

---

### 4️⃣ ❓ 2단계 스마트 영단어 퀴즈 시스템 (`QuizSection.js`)
- **1단계 (소리 퀴즈)**: 음성 발음을 듣고 4지선다형 뜻 맞추기.
- **2단계 (스펠링 퀴즈)**: 알파벳 주관식 스펠링 입력 퀴즈.
- **퀴즈 완수 및 출석도장 연동**: 2단계 퀴즈를 모두 맞히면 **오늘 출석 도장(💮)**이 자동으로 찍히며 출석 달력 탭으로 연결.

---

### 5️⃣ ⭐ 나만의 단어장 & ❌ 퀴즈 오답노트 독립 메인 탭 (`PersonalVocabSection.js`)
- **⭐ 나만의 단어장**: 보강이 필요한 단어를 즐겨찾기하여 모아보는 단어장.
- **❌ 퀴즈 오답노트 탭**:
  - 퀴즈에서 틀린 단어가 클라우드 DB에 자동 저장되어 오답노트에 수록.
  - 오답 단어 발음 청취 및 복습 완료 시 삭제/관리 가능.

---

### 6️⃣ 📅 날짜 선택 즉시 학습 연동 출석 달력 (`CalendarSection.js`)
- **날짜 클릭 학습 기능**: 출석 달력에서 출석이 안 된 날짜를 누르면 `"학습을 시작하시겠습니까?"` 안내 팝업 후 해당 날짜 단어 학습 탭으로 즉시 전환.
- **자동 출석 도장 💮**: 퀴즈 완수 시 선택한 해당 날짜 칸에 참잘했어요 출석 도장이 꾹 찍힘.
- **도장 클릭 당일 복습**: 출석 도장을 누르면 그 날짜에 공부했던 단어 30개 전체 목록 팝업 및 복습 지원.

---

### 7️⃣ 👨‍👩‍👧‍👦 학부모 전용 자녀 안심 학습 리포트 센터 (`ParentDashboard.js`)
- **군더더기 없는 전용 화면**: 학생 전용 헤더와 스마트 바를 완전히 숨긴 학부모 전용 안심 리포트 레이아웃.
- **자녀 탭 전환**: 등록된 다자녀(이승현, 이수민 등) 탭을 클릭하여 자녀별 학습 현황 전환.
- **👆 클릭 가능한 3대 인터랙티브 요약 카드**:
  - **`💮 누적 출석도장` 카드 클릭** ➔ 자녀의 출석표 달력 팝업 표출.
  - **`🔥 오늘 학습 단어수` 카드 클릭** ➔ 자녀가 공부한 모든 단어 리스트 및 🔊 발음 재생 팝업 표출.
  - **`❌ 오답노트 잔여` 카드 클릭** ➔ 자녀의 오답노트 단어장 팝업 표출.
- **학부모 피드백 코멘트**: 자녀의 회차별 학습량과 성취도에 대한 격려 메시지 자동 생성.

---

### 8️⃣ 🥷 센터 관리자 종합 페이지 (`AdminStudentManager.js` / `/admin`)
- **학생 및 학부모 종합 관리**: 신규 학생 등록, 학년, 하루 목표 단어 수, 학생 PIN, 학부모 이름, 연락처, 학부모 PIN 수정/삭제.

- **534개 영단어 DB 관리자**: 단어 추가, 한글 뜻 수정, 예문 등록 및 이미지 주소 관리.
